# PRESET KELUARAN PHOTO FIXER

Preset berikut adalah panduan instruksi, bukan jaminan bahwa model menghasilkan ukuran piksel atau karakter optik persis seperti kamera tertentu.

| Kebutuhan | Arahan keluaran | Hal yang perlu dijaga |
|---|---|---|
| Foto potret | Crop potret sesuai komposisi asli | Wajah, rambut, bahu, ekspresi |
| Foto profil | Persegi 1:1, subjek di tengah | Wajah tidak terpotong pada crop lingkaran |
| Instagram feed | 4:5 atau ukuran yang diminta platform | Area aman dan subjek |
| Story/Reels | 9:16 vertikal | Ruang teks atas/bawah |
| Thumbnail video | 16:9 horizontal | Subjek jelas dan ruang judul |
| Foto produk | Latar sederhana, detail tajam | Bentuk, warna, logo, dan label |
| Headshot profesional | Framing kepala/bahu, cahaya lembut | Identitas, ekspresi, pakaian |
| Foto film/analog | Grain dan karakter warna terkendali | Detail wajah dan warna kulit |

## Aturan ekspor

1. Tanyakan format jika aplikasi menyediakan beberapa pilihan dan format memengaruhi penggunaan.
2. Jangan mengklaim resolusi 4K/8K sebelum dimensi file benar-benar diperiksa.
3. Jangan memperbesar foto dengan cara mengarang tulisan, logo, nomor, atau ciri wajah.
4. Jika pengguna membutuhkan file transparan, cetak, atau ukuran piksel khusus, pastikan tool yang digunakan benar-benar mendukungnya.
5. Simpan sumber asli dan hasil akhir sebagai file terpisah bila memungkinkan.
