# Catatan Perubahan

## 1.0.0 — 19 November 2026

Rilis fondasi PHOTO FIXER.

- Membuat satu skill utama sebagai pengatur seluruh alur edit foto.
- Memisahkan fungsi menjadi 11 subskill khusus.
- Memindahkan 100 pintasan perintah dari materi sumber ke katalog berbahasa Indonesia.
- Menambahkan aturan menjaga wajah, tekstur kulit, tulisan, logo, bentuk produk, dan konteks foto dokumenter.
- Menambahkan daftar pemeriksaan kualitas dan preset keluaran.
- Menambahkan installer PowerShell dan shell untuk pemasangan lokal.
- Menambahkan manifest paket, tes struktur, dan alur pemeriksaan GitHub Actions.
- Menambahkan panduan pemasangan dan adaptasi lintas-platform dalam Bahasa Indonesia.

Catatan: rilis ini adalah paket instruksi Agent Skills. Ini bukan aplikasi editor gambar, server MCP, atau aplikasi ChatGPT yang sudah diterbitkan.
